# 使用說明

這份說明給「想在 Colab 上用 MOSS-Image 生圖」的人，不需要懂 ComfyUI 節點或命令列。
各功能目前是否通過 GPU 驗收，以介面上的標示為準（來源是 `configs/capabilities.json`）。

## 開始前

- 付費 Colab 帳號，且還有 compute unit 額度。工具不會替你購買資源，也不會掛載 Google Drive。
- 執行階段選 **L4 GPU** 與高 RAM（Notebook 已預設）。
- 模型約 20 GiB，存在 Colab 的暫存磁碟。執行階段被回收或刪除後，模型、作品與專案都會消失；
  要保留的作品請下載，或用專案選單匯出專案 ZIP。

## 啟動

1. 開啟 [Notebook](https://colab.research.google.com/github/Openclaw-Metis/MOSS-Image-Colab/blob/main/notebooks/MOSS_Image_Colab.ipynb)。
   Colab 會提醒這份筆記本來自 GitHub，按「仍要執行」。
2. 依序執行第 1～4 格：
   - 第 1 格取得程式（預設 `main`，可填固定 commit）。
   - 第 2 格檢查 L4、安裝固定版本環境、下載並校驗模型、啟動引擎。第一次約 10 分鐘。
   - 第 3 格啟動創作工作台，並印出**本次入口密碼**。
   - 第 4 格建立 Cloudflare Quick Tunnel，印出工作台網址。
3. 開啟第 4 格印出的網址，貼上第 3 格的密碼登入。

密碼每個執行階段都不同。網址是公開的網際網路位址，請不要分享網址或密碼；
任何拿到兩者的人都能使用你的 GPU 與作品。

## 五個分頁

**文生圖與排版**：輸入畫面描述後按「產生圖片」。「精細 50 步」品質較好；「加速 8 步」約快 10 倍，
但不使用負向提示詞。勾選「啟用畫框排版」可在畫布上拉框指定文字、物件與人物位置。
繁體中文字可能寫錯（實測 10 張有 3 張出錯），請逐字檢查；重要標題建議後製加字。
在模型頁加入的 LoRA 只能用在「精細 50 步」，最多 2 個。

**多圖指令修圖**：放入 1～4 張圖，用文字說明要怎麼改。圖 1 是主圖並決定輸出比例；
提示詞裡用「Picture 1／圖 1」指稱對應的圖，中間不要留空格。

**筆刷局部重繪**：放入來源圖，用筆刷塗出要改的地方，再描述要畫成什麼。
塗抹範圍外（扣掉柔邊）的像素會原封不動保留。整張塗滿需要另外勾選確認。

**視覺與深度控制**：放入來源圖，新圖會跟隨它的大致輪廓或深度；可另外上傳深度圖或色塊圖。
結果下方會顯示這次實際套用的估計輪廓／深度圖。「視覺參考」是實驗功能，效果不保證。

**模型與高解析**：查看模型下載狀態、切換主模型（SFT／Base）、刪除不用的檔案，
以及加入 Hugging Face LoRA（需填模型庫、完整 40 碼 commit 與檔案路徑；工具會鎖定該檔的 SHA256）。
「高解析分段放大」把作品分段放大到最大 2048×2048，每段最多 1.5 倍。
有工作進行中時，不能切換主模型或刪除檔案。

## 專案

左側「專案」區可以新建、開啟、改名、匯出、匯入與刪除專案。匯出的 ZIP 含輸入圖、遮罩、排版、
各分頁設定與作品，可在新的 Colab 執行階段匯入後接著編輯（匯入一律成為新專案，不含工作歷史）。

## 結束

1. 下載要保留的作品，或匯出專案 ZIP。
2. 執行最後一格「停止工具」（不刪作品與模型）。
3. 在 Colab 選「執行階段 → 中斷並刪除執行階段」，避免繼續消耗 compute unit。

## 疑難排解

| 看到的訊息 | 原因與處理 |
|---|---|
| 登入已失效，請重新登入 | 執行階段重啟後密碼會換新；回到 Notebook 第 3 格看新密碼。 |
| 專案已更新，請先重新載入 | 同一專案在別的分頁或視窗被修改；重新整理頁面後再提交。 |
| 此採樣預設不支援目前主幹 | 加速 8 步、修圖與控制只支援 SFT；到模型頁切回 SFT。 |
| 請先到模型頁下載… | 這個功能需要的檔案還沒下載；到「模型與高解析」按下載。 |
| 引擎工作狀態未確認 | 與引擎的連線中斷，無法確定 GPU 是否還在跑，工具會擋下新工作以免重複佔用 GPU。執行最後一格「停止工具」，再重新執行第 2～4 格（網址會換新）；中斷的工作可重新送出。 |
| 通道未回報網址 | 重新執行第 4 格；仍失敗時，Cloudflare Quick Tunnel 可能暫時無法使用。 |
| 頁面一直轉圈或空白 | 重新整理頁面；工作會在伺服器端繼續，重新整理後可找回原工作，不會重複生成。 |

## 隱私與使用限制

- 不得以真人照片製作換臉、私密或冒用他人身分的內容；Colab 對所有執行環境禁止 deepfakes。
- 上傳的圖片只存在你自己的 Colab 執行階段，存檔時會去除原始檔名與中繼資料；工具不會把素材上傳到其他服務。
- 加入的 LoRA 由你自行確認授權與用途；工具只保證下載的檔案與你填的 commit 完全一致。
