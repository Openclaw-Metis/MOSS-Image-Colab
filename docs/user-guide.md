# 使用說明

這份說明給「想在 Colab 上用 MOSS-Image 生圖」的人，不需要懂 ComfyUI 節點或命令列。
各功能目前是否通過 GPU 驗收，以介面上的標示為準（來源是 `configs/capabilities.json`）。

目前是**開發版**：各功能都在 Colab L4 實測過，但多圖修圖 3～4 張與輪廓控制沒有通過，繁中標題也可能寫錯，
所以還不算正式發布。各項結果見 [Stage 9 總表](stages/stage9.md)。

## 開始前

- 付費 Colab 帳號，且還有 compute unit 額度。工具不會替你購買資源，也不會掛載 Google Drive。
- 執行階段選 **L4 GPU** 與高 RAM（Notebook 已預設）。
- 第 2 格預設下載約 24.5 GB 的模型，存在 Colab 的暫存磁碟。執行階段被回收或刪除後，模型、作品與專案都會消失；
  要保留的作品請下載，或用專案選單匯出專案 ZIP。

## 啟動

1. 開啟 [Notebook](https://colab.research.google.com/github/Openclaw-Metis/MOSS-Image-Colab/blob/main/notebooks/MOSS_Image_Colab.ipynb)。
   Colab 會提醒這份筆記本來自 GitHub，按「仍要執行」。
2. 依序執行第 1～4 格：
   - 第 1 格取得程式（預設 `main`，可填固定 commit）。
   - 第 2 格檢查 L4、安裝固定版本環境、下載並校驗模型、啟動引擎。第一次約 10 分鐘以上，視下載速度而定。
     預設會下載五個分頁需要的全部模型：主模型、編碼器、VAE（約 20.2 GB），加上加速 8 步、多圖修圖、
     色彩／深度控制用的 LoRA 與幾何估計 MoGe（約 4.3 GB）。只想先試文生圖，可取消勾選 `DOWNLOAD_FEATURE_MODELS`，
     之後要用時再到「模型與高解析」分頁下載。Base 主模型（約 10 GB）只在要切換主模型時需要，不在預設下載內。
     重跑第 2 格不會重新下載已校驗的檔案。
     有 Hugging Face token 可加快下載、減少限流（選填）：到 Colab 左側「🔑 密鑰」新增名稱 `HF_TOKEN`
     （[建立 read 權限的 token](https://huggingface.co/settings/tokens)）、開啟「筆記本存取權」，再勾選第 2 格的
     `USE_HF_TOKEN`。token 只放在這個執行階段的環境變數，模型頁的下載也會用到；不會寫入檔案、輸出、專案或日誌，
     也不會跟著轉址送到下載 CDN。不勾選就用匿名下載，功能相同。
   - 第 3 格啟動創作工作台，並印出**本次入口密碼**（備用）。
   - 第 4 格建立 Cloudflare Quick Tunnel，印出**一次性登入連結**。
3. 點第 4 格印出的連結就會直接登入。連結 30 分鐘內有效、只能用一次；
   用過或過期時，重新執行第 4 格會換一條新連結（工作台網址不變），或在登入頁貼上第 3 格的密碼。

工作台網址是公開的網際網路位址。請不要分享登入連結或密碼：拿到未用過的連結或密碼的人，
就能使用你的 GPU 與作品。密碼與連結都只在這個執行階段有效。

## 五個分頁

**文生圖與排版**：輸入畫面描述後按「產生圖片」。「精細 50 步」品質較好；「加速 8 步」約快 10 倍，
但不使用負向提示詞。「畫面比例」可一鍵套用 1:1、4:3、3:4、3:2、2:3、16:9、9:16（約 1 MP），
也可直接拉寬高；改完立即生效，排版框會依比例跟著移動。寬高以 16 像素為單位，
因為模型把每 16×16 像素當成一格，其他數字會被引擎捨去，成品就不是設定的大小。
超過約 2.2 MP 的原生大圖屬實驗功能，大圖建議先生成再到「模型與高解析」分段放大。勾選「啟用畫框排版」可在畫布上拉框指定文字、物件與人物位置。
繁體中文字可能寫錯（實測 10 張有 3 張出錯），請逐字檢查；重要標題建議後製加字。
在模型頁加入的 LoRA 只能用在「精細 50 步」，最多 2 個。

**多圖指令修圖**：放入 1～2 張圖，用文字說明要怎麼改，例如「把圖 1 的外套換成圖 2 的外套」。
圖 1 是主圖，決定輸出比例；圖 2 會縮小到約 0.25 MP 再送進模型，適合提供衣物、顏色或場景，細節不一定完整保留。
放到 3～4 張是實驗功能：實測時模型常沒把圖 3、圖 4 的內容帶進成品。
指令裡用「Picture 1／圖 1」指稱對應的圖。圖要從圖 1 依序放；中間空了一格時，工具會請你確認重新編號。

**筆刷局部重繪**：放入來源圖，用筆刷塗出要改的地方，再描述要畫成什麼。
塗抹範圍外（扣掉柔邊）的像素會原封不動保留。整張塗滿需要另外勾選確認。
重繪強度預設 1.00；要加入新東西時保持 1.00，只想微調質感或顏色再調低（調低時模型常把背景補回去，而不是畫出新物件）。

**視覺與深度控制**：放入來源圖，新圖會跟隨它的大致構圖與深度；可另外上傳深度圖或色塊圖。
幾何來源預設「深度」，會連人物身形一起帶過來；要把人物換成別的角色時，調低控制強度或持續比例。
「輪廓」只適合背景是天空或遠景的照片，在棚拍或室內背景下常整片變白，等於沒有控制。
結果下方會顯示這次實際套用的估計輪廓／深度圖。「視覺參考」是實驗功能，傾向照抄參考圖，效果不保證。

**模型與高解析**：查看模型下載狀態、切換主模型（SFT／Base）、刪除不用的檔案，
以及加入 Hugging Face LoRA（需填模型庫、完整 40 碼 commit 與檔案路徑；工具會鎖定該檔的 SHA256）。
「高解析分段放大」把作品分段放大到最大 2048×2048，每段最多 1.5 倍。
有工作進行中時，不能切換主模型或刪除檔案。

## 大約要多久

以下是 Colab L4 上的實測時間，供估算用；第一次執行時還要多載入模型的時間。

| 工作 | 約需 |
|---|---|
| 加速 8 步，1 MP | 10～15 秒 |
| 精細 50 步，1 MP | 110～150 秒 |
| 多圖修圖（1～2 張） | 80～95 秒 |
| 筆刷重繪 | 70～80 秒 |
| 色彩／深度控制 | 約 60 秒 |
| 原生 1456×1456 | 約 250 秒 |
| 分段放大到 2048×2048 | 約 520 秒 |
| 原生 2048×2048（實驗） | 約 610 秒 |

## 專案

左側「專案」區可以新建、開啟、改名、匯出、匯入與刪除專案。匯出的 ZIP 含輸入圖、遮罩、排版、
各分頁設定與作品，可在新的 Colab 執行階段匯入後接著編輯（匯入一律成為新專案，不含工作歷史）。

## 結束

1. 下載要保留的作品，或匯出專案 ZIP。
2. 執行最後一格「停止工具」（不刪作品與模型）。
3. 在 Colab 選「執行階段 → 中斷並刪除執行階段」，避免繼續消耗 compute unit。

## 疑難排解

| 看到的訊息 | 原因與處理 |
|---|---|
| 登入已失效，請重新登入 | 工作台重啟後舊登入會失效；重新執行第 4 格取得新的登入連結。 |
| 登入連結已用過或過期 | 每條連結只能用一次、30 分鐘內有效；重新執行第 4 格，或貼上第 3 格的密碼。 |
| 專案已更新，請先重新載入 | 同一專案在別的分頁或視窗被修改；重新整理頁面後再提交。 |
| 此採樣預設不支援目前主幹 | 加速 8 步、修圖與控制只支援 SFT；到模型頁切回 SFT。 |
| 請先到模型頁下載… | 這個功能需要的檔案還沒下載（第 2 格取消了 `DOWNLOAD_FEATURE_MODELS`，或要用 Base）；到「模型與高解析」按下載。 |
| 引擎工作狀態未確認 | 與引擎的連線中斷，無法確定 GPU 是否還在跑，工具會擋下新工作以免重複佔用 GPU。執行最後一格「停止工具」，再重新執行第 2～4 格（網址會換新）；中斷的工作可重新送出。 |
| 通道未回報網址 | 重新執行第 4 格；仍失敗時，Cloudflare Quick Tunnel 可能暫時無法使用。 |
| 頁面一直轉圈或空白 | 重新整理頁面；工作會在伺服器端繼續，重新整理後可找回原工作，不會重複生成。 |
| 重新整理後結果區顯示「還沒有作品」 | 結果區只顯示目前追蹤的工作；它還沒完成時是空的，完成後就會出現。之前的作品仍在專案裡，可用「打包作品 ZIP」下載。 |
| 舊的工作台網址打不開（錯誤 530） | 執行階段已停止或刪除，通道也跟著關閉；重新執行第 1～4 格會得到新網址。 |

## 隱私與使用限制

- 不得以真人照片製作換臉、私密或冒用他人身分的內容；Colab 對所有執行環境禁止 deepfakes。
- 上傳的圖片只存在你自己的 Colab 執行階段，存檔時會去除原始檔名與中繼資料；工具不會把素材上傳到其他服務。
- 加入的 LoRA 由你自行確認授權與用途；工具只保證下載的檔案與你填的 commit 完全一致。
